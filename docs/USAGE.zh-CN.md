# Agent Orbit

A small native macOS monitor for local Codex CLI and remote Codex CLI / Claude Code CLI sessions.

**5.2.6 — 悬浮球右键手动运行标记、同圈资源声浪、空闲／运行比例图，以及 Claude 后台智能体识别。**

用紧凑的置顶窗口或桌面会话环，查看 Agent 何时真正等待下一次输入、何时需要处理异常。绿色表示等待，黄色表示待处理，红色表示异常；运行色随皮肤变化，也可选择经典配色中的橙色。待核实与离线各有独立状态色。保留终端与在线 Agent 数量只提供上下文，不会把已结束的主对话误判成运行中。

## 功能

- 同时监控本机 Codex 和 SSH 远端 Codex / Claude；两种来源独立显示连接状态。
- 本机自动发现桌面端、CLI、VS Code 当前打开的 Codex 主会话，读取实际开始、结束与异常记录。
- 原生设置窗口：监控来源、SSH 主机、tmux Socket、两种关注列表、采样间隔、提示音、置顶、透明度、悬浮球大小及显示内容。
- 四套皮肤：霓虹深空、极光紫、石墨黑、晴空浅色，同时应用到面板和会话环。名字、状态文字、圆弧与标记使用同一套状态色，可选择皮肤状态色或经典状态色，保存后立即刷新。
- 完成与异常提示音可分别开关；已恢复的问题自动消失，不显示执行历史。
- 圆周会话名、双圈布局、真实输出活动轨迹；小号球显示待响应和最久等待，单击切换大小、双击打开面板、拖动移动。
- 分会话显示运行/等待时长与输出/工具速度；默认等待 5 分钟后提醒一次，可调整阈值、稍后提醒或静音本轮。
- 自行创建互斥会话组，选成员或拆组；默认各自独立，组内任一成员运行时不催其他等待成员。完整球以细双色比例弧显示累计空闲／运行占比，悬停查看时长。
- 外围声浪可选择样式与配色，包括多层等离子、极光光带、雷达涟漪，并调整高度和密度；变化来自实际输出活动。
- 用量总览显示会话运行占比、实时消耗、总消耗、上游输出速度及工具完成速度；支持本机 Codex 与远端 Codex / Claude，缺失与不完整统计会标明。
- 只读采集、Python 标准库，无遥测、账户注册、HTTP 服务或远端 hooks。

## 快速开始

直接使用发布版只需 **macOS 13+**，Python 运行环境已经内置；无需 Codex、Node.js 或任何插件来启动本应用。从源码构建时才需要 Python 3.9+ 和 Xcode Command Line Tools。远端模式另需可无交互登录的 SSH，以及远端 Python 3、tmux。本机采集使用系统 `ps` 和 `lsof`。

```bash
sh build_desktop.sh
sh ./agent-orbit panel
```

也可双击构建出的 `Agent Orbit.app`。首次安装默认只启用本机监控；已有安装会沿用迁移后的远端配置。点击面板右上角齿轮，或菜单栏 `AO → 设置…`，打开统一设置。

设置中的 SSH 主机填写你已有的 SSH 配置别名或 `user@host`。Socket 留空使用远端默认 tmux，使用自定义 Socket 时填写完整路径。远端关注列表每行一个会话名，留空表示全部。

本机关联当前打开的 Codex 根会话，可选择全部或逐个关注。未使用可识别运行记录的版本会显示待核实。点击本机会话会唤起已安装的 Codex 客户端；远端卡片进入原 tmux 会话。退出 tmux 连接使用 **Ctrl+B**，松开后按 **D**，远端任务继续运行。

## 简短命令

新命令为 `ao`，原有 `cr` 与 `codex-remote` 入口继续兼容。将下面这行加入 `~/.zshrc`，路径替换为你的项目目录：

```zsh
source '/path/to/agent-orbit/shortcuts.zsh'
```

```bash
ao p                # 桌面面板
ao                  # 终端持续监控远端（新安装没有远端配置时监控本机）
ao local            # 终端持续监控本机 Codex
ao l                # 单次列出
ao + work1 work2    # 添加远端关注
ao - work2          # 移除远端关注
ao f                # 查看远端关注
ao work1            # 进入远端会话
```

终端监控使用 ↑↓ 选择、Enter 进入远端、v 查看画面、q 退出。运行中的旧终端监控需要退出并重新启动才能加载新代码。

## 设置与数据

macOS 个人数据保存于 `~/Library/Application Support/Agent Orbit/`：

- `settings.json`：来源、外观、声音等设置。
- `follow.json`：远端关注列表，桌面与命令行共用。
- `.logs/connection.log`：有界连接诊断，不保存会话正文。

源码和应用包不携带个人设置。已有安装自动沿用原 `Codex Remote` 配置目录；新安装使用 `Agent Orbit`。旧项目中的 `follow.json` 在首次迁移时保留原件。可设置 `AGENT_ORBIT_DATA_DIR` 使用独立配置目录，也兼容旧的 `CODEX_REMOTE_DATA_DIR`；非 macOS 的终端模式使用 `$XDG_CONFIG_HOME/agent-orbit`。本机 Codex 数据目录可在设置中修改，默认使用 `CODEX_HOME` 或 `~/.codex`。

设置示例见 [settings.example.json](../settings.example.json)。保存后生效，变更连接参数时仅重新连接对应来源。皮肤和显示选项不会重启远端 Agent。

到“设置 → 监控 → 互斥会话组”新建组、填写名称、勾选至少两个成员。圆周上整个组只占一个位置，面板合并成可展开的卡片，展开后可分别进入成员会话。移出成员或删除组可恢复独立统计；分组不会自动改变关注列表。全组明确等待时共同计时并只提醒一次，成员缺失或离线时暂停空闲统计。具体口径见 [待响应与悬浮球](RESPONSE.md)。

## 外观与外围声浪

### 手动标为运行中

如果你确认会话仍在工作，但自动状态显示等待，可在完整悬浮球上右键对应会话名或组名，选择“手动标为运行中”。小号球或中心空白处的右键菜单提供“会话与互斥组”子菜单，选择目标后操作。界面显示“手动运行中”，也可右键“取消手动运行”恢复自动判断。

标记从当前结果建立基线；只有标记之后的新回复结果才解除，终端刷新、工具中间输出和 Token 更新不会解除。互斥组的任一成员产生新回复结果即可解除该组标记；如果自动记录确认仍有工作，解除后继续按实际状态显示。异常、待确认和离线优先显示。手动标记只影响本机监控，不会向 CLI 发送输入；退出并重新启动监控后需重新标记。

### 外观设置

在“设置 → 外观”中选择皮肤和“状态配色”，并调整悬浮球。默认的“皮肤状态色”为每套皮肤提供六种状态颜色；“经典状态色”在各皮肤中使用橙色运行、绿色等待、黄色待处理、红色异常、紫色待核实、灰色离线，并按深浅背景调整色值。名字、状态文字、圆弧与标记始终遵循同一状态。

外围声浪支持以下独立设置：

| 设置 | 可选内容 |
| --- | --- |
| 样式 | 随皮肤（`theme`）、全息声浪柱（`bars`）、曲线（`curve`）、光点（`dots`）、等离子双波（`plasma`）、极光光带（`aurora`）、雷达涟漪（`radar`）、关闭（`off`） |
| 配色 | 随皮肤（`theme`）、Ice、Aurora、Ember、状态色（`status`） |
| 高度 | 50%–150% |
| 密度 | 60%–160% |
| 多层资源声浪 | 默认开启；资源通道在同一圈叠加，颜色随皮肤切换 |
| 低活动灵敏度 | 60%–180%，放大较少的真实活动，不为静默生成假流量 |

多层模式的输出/I/O、工具事件和 TCP 网络活动共用一条圆周基线，以不同颜色和线宽叠加；内存为静态标记。只有正在运行的会话显示声浪，进入等待、待处理、异常或离线后立即清除，恢复运行先建立新基线。组内等待成员的终端心跳不会加入工作波形。悬停可查看资源数值与覆盖范围；共用进程或 socket 会注明共享，macOS 无法采集的网络和 I/O 保持未知。资源数值不用于判断任务是否完成，详见[指标口径](METRICS.md#资源声浪)。

多层模式使用固定的通道图形与皮肤资源色；关闭“多层资源声浪”后，恢复原有样式和配色选择。高度、密度与低活动灵敏度在两种模式下均可调整。

声浪由最近输出或日志变化驱动。Ice、Aurora、Ember 是运行与等待状态下的装饰渐变；待处理、异常、待核实和离线优先显示对应状态色。声浪配色中的 `theme` 和 `status` 均遵循当前全局状态配色。高度、密度与配色只影响显示，不改变采样或状态判断；图形不表示 CPU 利用率、Token 速度或推理效率。关闭声浪后会话状态仍照常更新。

默认悬浮球缩放 85%、声浪高度 130%。声浪没有真实活动时保持安静，开启减少动态效果后仍按真实采样更新、过期。完整球用细双色弧表示累计空闲／运行占比，为名称留出空间；具体时长在悬停提示中。单击可缩成小号球，双击打开面板。

“全息声浪柱 · 分段峰值”沿用 `bars` 设置。分段柱身、亮色细芯、峰值短帽和短暂光尾展示近 24 秒输出的强弱变化；最新输出触发亮点，静默后动态效果收敛。已有声浪柱用户会直接获得新外观，高度、密度和皮肤配色继续生效。

设置文件保留旧键 `orbit_label_color`：`theme` 现在表示全局皮肤状态色，`status` 表示全局经典状态色。已有设置可继续使用，无需重建关注列表。开发接口和各皮肤色值见 [颜色分析与统一接口](THEMING.md)。

## 用量总览

每张卡优先显示该会话的等待或运行时长，以及自己的输出/工具速度。顶部集中显示待响应数量与最长等待，方便选择下一步处理哪个会话。久等提醒与两种悬浮球的操作见 [待响应与悬浮球](RESPONSE.md)。

面板显示总运行率、近 30 秒新增 Token、实时消耗、总消耗、上游速度、工作速度。每个会话也有独立的新增量和精确累计数字；悬浮球中心始终显示近 30 秒实际新增量，名称旁的细双色弧显示累计空闲／运行占比。Token 读取 CLI 已报告的实际记录；速度分别采用 30 秒 Token 窗口和 60 秒工具完成窗口。累计范围是当前关注主会话，包含已核实的缓存输入，不重复叠加子智能体日志。

查看统计覆盖数；首次核对、字段缺失或断线时可能出现 `—` 或部分统计。Claude 常在响应完成时写入用量，因此上游速度是日志结算的窗口均速。总运行率表示会话忙碌比例，不是机器利用率。完整口径见 [用量指标](METRICS.md)。

## 启动与连接检查

首次连接失败时，面板会显示主机、网络、认证或设置错误，并提供“检查设置”入口。请核对 SSH 主机是否与终端中正常使用的别名一致，以及 tmux Socket 是否正确。修正并保存后会自动重连。

无效设置也会显示具体原因，修正后可自动恢复；不会一直停在初始化。禁用本机监控后，远端连接失败不会自动启用本机来源。

## JSONL 接口

```bash
sh ./agent-orbit watch --json                  # 原始远端采样
sh ./agent-orbit --local watch --json          # 原始本机采样
python3 -u desktop_bridge.py                # 按设置合并的处理后数据流
```

每行一个 JSON 对象，适合子进程逐行读取。桥接流包含 `rows`、`events`、`error_events`、`active_error_events`、`connections`、`local_sessions`、`metrics` 和全局连接概况。每行会话的 `source` 为 `local` / `remote`，`available` 表示该行来源是否新鲜；**不要用全局 `connected` 代替单行状态**。本地与远端的会话 ID 互不冲突。

`background_agents` 表示日志确认正在工作的子任务，`background_agents_total` 是可识别的在线总数，`background_terminals` 是保留终端数量。读取这些数值时检查相应的 `*_observable` / `background_checking`。本机共享 app-server 的终端无法准确归属单个对话时省略数量，不猜成 0。当前不提供 HTTP / REST 接口。

## 状态识别与边界

采样默认 0.5 秒，实际延迟包含采集和传输。输入页面与正文稳定后才确认结束；仍在思考、请求未结束或实际子任务工作时不会仅凭静默报完成。保留的 shell 或服务不会阻止主对话显示等待输入。首次打开和重连不补报历史完成。

本机状态来自当前打开的会话日志，远端还结合 tmux 当前页面。Codex / Claude 的内部日志与终端格式会变化，未识别状态会明确标注。终端活动图表示输出变化，不是 CPU 利用率或 Token 速度。详细规则见 [docs/STATUS.md](STATUS.md)。

## 开发与发布

```bash
python3 -m unittest -v
sh scripts/check_orbit_waves.sh  # macOS：声浪状态、重连及比例图回归
sh build_desktop.sh
python3 scripts/package_release.py
# 或 make package
```

`dist/` 生成源码 ZIP、当前架构的 macOS 应用 ZIP 与 SHA256 校验文件；仅在显式使用 `--include-demo` 时额外复制已有介绍视频。发布脚本按明确文件名单打包，排除关注列表、个人设置、日志、备份与缓存。应用包自带采集脚本和固定版本的可搬移 Python 运行环境，移动到其他目录后可独立使用。当前使用本地临时签名，正式面向陌生用户分发时应由发布者完成 Developer ID 签名与公证；此项目不会自动上传 GitHub。
