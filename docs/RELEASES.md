# 更新说明

## 5.2.7 · main 预览 · 2026-11-23

此版本已进入主分支，尚未提供新的 Release 安装包；稳定下载仍为 5.2.6。

- **声浪有高低、有分工**：输出、进程 I/O、工具结果、TCP 网络四种动态信号叠在同一条圆周时间轴上，配合静态内存弧。各通道采用独立柔和标尺，降低信号全部顶格、看起来等高的问题；不使用随机波动制造活动。
- **五种形状与皮肤配色**：光带、分段柱、菱形针、细曲线和内存弧各有含义，随皮肤统一变化。等待、异常、离线时停止活动波形，未知指标保留未知。
- **随时查阅说明**：悬浮球右键或设置中打开“声浪图说明”，可点选图例，了解数据来源、单位、共享资源和平台覆盖。完整文档见 [声浪图说明书](WAVE_GUIDE.zh-CN.md)。
- **按需绘图**：绘图刷新与采集、状态更新分开；静默、缩小或隐藏时降低绘图开销。短暂视觉过渡仅呈现已经收到的真实数据，状态变化即时生效。
- **新的产品介绍**：首页以脱敏的原生界面和静态图解介绍 CLI 监控，不包含私人会话或真实任务内容。
- **首次配置指南**：下载应用后按本机或 Linux 远端流程配置，含 SSH 验证、tmux 会话与 Socket 查找、设置字段和排障；无需先克隆项目。[从这里开始](GETTING_STARTED.zh-CN.md)。
- **独立应用进入远端**：补齐打开原 tmux 会话需要的命令入口，并使用应用自带 Python；修复仅对 main 新构建生效。稳定 5.2.6 的临时进入方法已写入首次指南。

验证：321 项 Python 测试、3093 项皮肤断言、97 项会话断言、147 项声浪断言和 15 项界面模型断言通过；原生构建、签名与深浅皮肤导出校验通过。独立入口回归使用移动后的应用目录、无系统 Python 的 PATH 和模拟 SSH，验证命令能够到达正确的原会话。

## 5.2.6 · 2026-11-21

本次汇总 5.2.1 之后的本机改进。Agent Orbit 是独立的 macOS 应用，用于监控本机 Codex CLI 与 SSH 远端 Codex CLI / Claude Code CLI。

- **状态更准确**：Claude 按最新生命周期记录确认前台完成，旧历史不会覆盖新完成；支持结果中的 `isAsync` / `async_launched`，前台回复后仍执行的后台智能体继续算运行，完成通知到达后解除。
- **手动运行标记**：在悬浮球右键会话或互斥组，手动标为运行中；从当前结果建立基线，新回复结果到达后解除，或随时右键取消。刷新、工具中间输出、Token 更新和旧历史不会解除，异常与离线仍优先显示。
- **声浪与状态一致**：资源通道共用同一圆周基线，以不同颜色和线宽叠加；等待、停止、异常和离线后立即清除波形。组内空闲成员的终端心跳不再贡献声浪，恢复运行先建立新基线。
- **资源与低活动显示**：工具事件、输出/I/O、TCP 网络与静态内存标记分别取自实际记录；可调整灵敏度，颜色随皮肤变化。未知、部分覆盖和共享资源会标明；macOS 当前资源采集提供 RSS，网络与 I/O 不猜成零。
- **更紧凑的会话环**：名称旁的细双色弧表示累计空闲／运行比例，悬停查看到秒的时长。互斥会话组只占一个位置，面板可展开查看成员。
- **真实 Token 数量**：各会话及悬浮球显示近 30 秒新增 Token，面板显示完整累计，缺失统计明确标识。

### 下载与升级

下载 `Agent-Orbit-5.2.6-macos-arm64.zip`，退出旧版应用，解压替换后重新打开。已有关注列表、互斥分组、皮肤与其他个人设置沿用；应用自带 Python，无需安装 Codex 插件来启动。

提供 Apple Silicon（arm64）应用包、源码 ZIP 和 `SHA256SUMS`。Intel Mac 可从源码构建。支持 macOS 13+；社区构建使用本地签名，尚未进行 Apple 公证。旧版介绍视频继续保留在 [5.2.1 发布页](https://github.com/Arkaida/agent-orbit/releases/tag/v5.2.1)。
