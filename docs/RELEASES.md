# 更新说明

## 5.3.3 · 2026-11-25

本次公开发布汇总 5.2.6 之后的全部改进。Agent Orbit 独立运行，监控已有的本机 Codex 与 Linux SSH/tmux Codex CLI / Claude Code CLI，会话无需由 Orbit 启动。

- **五路真实活动**：对话输出、CPU、磁盘、GPU、TCP 网络在同一圆周与24秒时间轴叠加。输出按明确助手正文增量观测，硬件按关联进程采样；未知不补零，显存与常驻终端不冒充工作。
- **六种统一声浪皮肤**：光柱、辉光、极光、雷达、曲线、端点统一应用到五层，以颜色区分来源。指标短暂缺失时保留真实历史至原期限；恢复先建基线，不补造断线流量。
- **Claude 后台实验**：已记录任务的输出增长、精确关联的进程分支活动，以及保留精确会话身份的脱离进程可提供运行证据；前台可输入信息单独保留。常驻 shell 数量和整台服务器繁忙不单独判运行。
- **Codex 长任务识别**：运行计时括号外的后台终端附注、快捷键及窄窗截断可正确识别。开始事件已离开日志尾部时，当前 Working 界面仍能提供状态；正文引用、草稿和历史异常不会触发新运行或旧告警。
- **采集与稳定性**：共用不可变进程快照、公平有界采样，复核进程身份与会话归属，降低共享资源误记。保留原生文字排版缓存、异常隔离与绘图降频改进。
- **配置与说明**：修复独立应用的远端进入按钮，补齐首次使用指南、应用内声浪图解、资源口径、平台覆盖及皮肤接口文档。慢采样时，对话输出的连续性阈值随设置调整，保留断档与重连基线保护。

## 5.3.2 · 本机预览 · 2026-11-25

声浪皮肤统一控制五层的造型。光柱、辉光、柔带、雷达、曲线与端点六套画法应用到每一通道，颜色区分对话输出、CPU、磁盘、GPU和网络；切换皮肤不改变实际数值。设置与应用内图解使用同一皮肤配置，并说明跟随界面皮肤与独立选择的区别。

修复运行中一帧指标缺失或过期就抹掉整段声浪的问题。当前采集覆盖与已观测历史分开，真实历史按原时间保留到24秒期限；缺失处不补峰，恢复先建基线。等待、异常、未知任务状态、离线和确认的身份变化继续清除对应历史。

修复 Codex 运行提示带额外快捷键、长输入框及重连时可能漏掉运行状态的问题。连接、日志替换和截断时从已验证根日志的有限尾部恢复任务状态；不重播历史异常提醒。大段日志跳读不再继承旧任务状态，残留终端数量仍不单独代表运行。

验证：433 项 Python 测试、1169 项声浪与悬浮球断言、3141 项皮肤断言、97 项会话断言及15项界面模型断言通过，完整应用构建与签名通过。声浪测试包含六种皮肤逐通道的真实绘制、统一几何、采样缺口、身份切换、换组和别名去重。本次只更新本机，不发布GitHub或生成视频。

## 5.3.1 · 本机预览 · 2026-11-25

## 5.3.0 · 本机预览 · 2026-11-25

四层声浪改为 CPU、磁盘、GPU、网络，替换旧输出与工具事件；CPU按连续时间区间呈现，GPU按真实逐进程SM采样点绘制，查询周期不冒充观测窗口。磁盘使用活跃线程read_bytes/write_bytes，RSS保留悬停说明。四层沿用统一皮肤，在同一圆周叠加，未知不补零。

修复Claude前台已回复、后台实验仍推进却被判等待的问题：任务输出连续增长或与任务精确关联的进程分支持续活动时显示后台实验运行中，前台可输入单独标记。支持通过精确Claude会话标识关联脱离原树的NVIDIA实验，以及结构化输出文件、持久Bash任务和异步Workflow的生命周期；完成与停止通知清除对应任务，常驻终端数量不单独判运行。修复大型会话耗尽全局线程预算导致其他会话长期缺失I/O的问题，总采样预算保持不变。

验证：406 项 Python 测试、207 项声浪与悬浮球断言、3054 项皮肤断言、97 项会话断言和 15 项界面模型断言通过；远端真实后台实验验证覆盖任务分支及脱离原树的 GPU 进程，活动停止后不因常驻终端继续判运行。额外覆盖采样缺口不误报完成、GPU缺失不能由CPU零覆盖，以及首次发现和后续查询中的PID复用。本次只更新本机，尚未发布新Release或安装包。

## 5.2.9 · 本机预览 · 2026-11-25

优化底层进程与资源采集。每轮共用只读进程快照和父子索引；关注筛选前统计共享宿主，无法确认会话归属时保留未知。采样复核进程启动身份与父子关系，失效祖先的后代不再继续归入旧会话。

CPU 按进程树连续执行时间计算，悬停可查看，`100%` 表示一个逻辑核。Linux I/O 改为累计已观测活跃线程的自身增量，避免父进程回收子进程后重复统计；新线程、身份变化、缺口和计数回退先建立基线。其他目标树 FD 不完整时，不把潜在共享 TCP 误报为独占。资源采集保持有界、异步，资源活动不会覆盖明确的会话完成事件。详细口径与轮询限制见 [进程采集说明](PROCESS_COLLECTION.zh-CN.md)。

验证：354 项 Python 测试、189 项声浪与悬浮球断言、3093 项皮肤断言、97 项会话断言和 15 项界面模型断言通过；本机真实 CPU 采样、Linux 独立测试进程的 CPU / I/O 与回收不重复计数验证通过。本次仅更新本机，未发布新的 GitHub Release 或安装包。

## 5.2.8 · main 预览 · 2026-11-24

修复悬浮球绘制圆周会话名时偶发的文字排版异常。旧路径每帧逐字调用 AppKit 测量；新版使用有界缓存复用 CoreText 布局，并在原生排版、颜色解析和绘制内隔离 Objective-C 异常。单个标签失败时显示几何占位，其余绘制、监控与提醒继续。文字布局不保存状态色，切换皮肤或状态仍立即使用新颜色。

额外覆盖圆周布局计算与中心文字的相同测量路径；校验有限字号、坐标与文本长度。异常诊断仅记录处理阶段、类别、字号与字符数，并限制频率，不保存会话名称或对话内容。新增可控异常注入、Unicode、缓存上限、绘图状态恢复与真实悬浮球重绘回归；故障注入接口仅存在于测试构建。

验证：321 项 Python 测试、130 项原生异常边界断言、116 项文字布局断言、164 项声浪与真实悬浮球绘制断言、3093 项皮肤断言、97 项会话断言和 15 项界面模型断言通过；完整应用构建、签名校验及脱敏深浅皮肤导出通过。正式应用不包含故障注入接口。

此次处理已确认的崩溃路径；原报告没有记录底层触发字符或字体条件，因此不宣称已经复现 macOS 内部偶发缺陷。尚未新增 Release 安装包；稳定下载仍是 5.2.6，新修复需要从 main 构建。

## 5.2.6 · 2026-11-21

本次汇总 5.2.1 之后的本机改进。Agent Orbit 是独立的 macOS 应用，用于监控本机 Codex CLI 与 SSH 远端 Codex CLI / Claude Code CLI。

- **状态更准确**：Claude 按最新生命周期记录确认前台完成，旧历史不会覆盖新完成；支持结果中的 `isAsync` / `async_launched`，前台回复后仍执行的后台智能体继续算运行，完成通知到达后解除。
- **手动运行标记**：在悬浮球右键会话或互斥组，手动标为运行中；从当前结果建立基线，新回复结果到达后解除，或随时右键取消。刷新、工具中间输出、Token 更新和旧历史不会解除，异常与离线仍优先显示。
- **声浪与状态一致**：资源通道共用同一圆周基线，以不同颜色和线宽叠加；等待、停止、异常和离线后立即清除波形。组内空闲成员的终端心跳不再贡献声浪，恢复运行先建立新基线。
- **资源与低活动显示**：工具事件、输出/I/O、TCP 网络与静态内存标记分别取自实际记录；可调整灵敏度，颜色随皮肤变化。未知、部分覆盖和共享资源会标明；macOS 当前资源采集提供 RSS，网络与 I/O 不猜成零。
- **更紧凑的会话环**：名称旁的细双色弧表示累计空闲／运行比例，悬停查看到秒的时长。互斥会话组只占一个位置，面板可展开查看成员。
- **真实 Token 数量**：各会话及悬浮球显示近 30 秒新增 Token，面板显示完整累计，缺失统计明确标识。
